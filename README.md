# 점심결재 대작전 · points5

공개 게임 `chfhrdl01-netizen/hoonjung45`의 campus4를 이어 수정한 `party30-20261115-points5` 소스입니다. 전원 5판 누적 점수전으로 진행하며, 화면 HTML과 게임 코드·스타일을 분리했습니다. points5 런타임의 공개 배포와 실제 5판 진행을 확인했습니다.

## 게임 진행

- 온라인은 2~8명이 메뉴와 캐릭터를 고르고 모두 준비하면 시작합니다. 전원이 다섯 판에 참여하며, 낮은 점수를 받은 사람도 다음 판을 계속합니다. 혼자 하는 랜덤 5판 연습도 컴퓨터와 같은 누적 점수 방식으로 진행합니다.
- 각 경기의 순위 점수를 합산합니다. 4명이면 4·3·2·1점, 2명이면 2·1점이며 동순위에는 같은 점수를 줍니다. 최종 동점은 공동 순위로 유지하고, 점심 대표 메뉴만 공동 1위 중 한 번 추첨합니다.
- 5판 종료 → 최종 점수표와 시상식 → 메뉴 승낙 → 희망자 커피 게임 → 엔딩으로 이어집니다. 참가자 기권으로 일찍 끝나면 실제 완료한 경기 수를 표시합니다.
- 메뉴 이의는 신청자당 한 번입니다. 이의 결투는 점심 메뉴만 바꾸며, 확정된 누적 점수·순위·공동 우승자 기록은 유지합니다. 이의를 받아 패한 이전 메뉴 제안자는 다시 도전할 수 없습니다.
- 경기 완료 뒤 대표 메뉴 제안자가 나가도 확정 점수표를 유지합니다. 남은 참가자가 메뉴 승낙을 계속할 수 있도록 대표 메뉴를 넘깁니다.

## 캐릭터와 조작

- 공식 대학 안내 및 재학생 전공 자료를 근거로 14개 대학·학부 그룹, 학과·전공 118개를 수록했습니다. 모집중지 재학생 전공 17개와 학사 계약학과를 포함하고, 2027 개편 이름은 검색 별칭으로 지원합니다. 출처와 범위는 `work/departments-official.json`에 있습니다.
- 근로생은 삭제했습니다. 시설물관리 역할은 별도로 유지했습니다.
- 학과 선택은 큰 버튼으로 여는 카드 창입니다. 대학별 버튼, 예전 이름 검색, 캐릭터 미리보기, 24개씩 더 보기를 제공합니다.
- 기존 캐릭터 얼굴·몸·색을 보존하며 학과별 옷·안경·가운·헤드셋 등 16종의 의상을 더했습니다. 학과 순서가 바뀌어도 모습이 유지되며 SVG를 재사용합니다.
- 모바일 세로는 왼쪽 방향키·오른쪽 액션 버튼, 가로는 왼쪽 안내·가운데 경기장·오른쪽 조작부로 배치합니다. 게임 조작 버튼의 텍스트 선택과 길게 누르기 메뉴를 막고, 회전 시 눌린 입력을 해제합니다.
- 1대1은 본인 키패드 하나만 표시합니다. 관전자는 조작하지 못하며, 로컬 키보드 두 세트는 유지합니다. 짧은 가로 화면에서는 경기장과 조작부를 나란히 배치합니다.
- 엔딩의 건너뛰기·ESC·결과 보기 우회를 제거했습니다. 커피 배달 장면은 13초이며 참가자별 확정 주문을 오른쪽(모바일 아래)에 표시합니다. 전체 엔딩은 인원에 따라 40~43.5초, 종료 시 모두 로비로 돌아갑니다.
- 경기 시간이 틱 지연으로 유실되던 부분을 고치고, 호스트의 실제 마감시각과 참가자 시계 차이를 반영합니다. 늦은 입력은 과거 판정창에 적용하지 않습니다. 긴 중단은 최대 66틱으로 복구하므로 중단 중 모든 물리 충돌을 재생하는 방식은 아닙니다.
- 다리 완성 점수 우선순위와 횡단보도 도약 방향 오류를 수정했습니다. 본선 점수전 격투·식판에서는 탈락 후 복귀하며 기존 서바이벌 규칙은 유지합니다.

## 소스 구조와 빌드

수정할 기능별 원본 위치는 [게임 소스 구조](work/source/README.md)에 정리했습니다. `work/base.html`은 화면 HTML 템플릿이며, `work/source/manifest.json`이 소스 결합 순서와 배포 파일 이름을 관리합니다. 게임 판정·점수 진행·메뉴 승낙 등은 `work/`의 기능별 모듈에 있습니다.

저장소 루트에서 실행합니다.

```sh
node work/build.mjs
```

다음 세 파일을 루트와 `dist/`에 동일하게 생성합니다.

| 배포 파일 | 내용 |
| --- | --- |
| `index.html` | 화면 HTML |
| `assets/styles-points5.css` | 기능별 CSS를 원래 우선순위로 결합한 스타일 |
| `assets/app-points5.js` | 실행 순서를 보존한 게임 코드 |

배포할 때는 CSS·JS를 먼저 올리고 `index.html`을 마지막에 반영합니다. 배포용 파일을 직접 수정하면 다음 빌드에서 덮어씁니다. 원래 방 통신·메인 앱·화면 장식의 세 실행 범위를 유지하므로 소스 조각을 각각 ES 모듈로 불러오지 않습니다.

QA 화면은 `node work/build-qa.mjs`로 별도 생성하며, 공개 배포에는 QA 코드를 포함하지 않습니다.

점수전 검사는 2·3·8명 전원 참여, 공동 순위와 대표 메뉴, 기권 처리, 메뉴 이의전 이후 점수표 보존을 확인합니다. 소스 구조 검사는 실행·CSS 순서, 문법, 배포 경로, 루트와 `dist` 파일 일치 및 QA 코드 제외 여부를 확인합니다.

공개 points5에서 다음 실제 진행을 확인했습니다.

- 혼자 연습: 컴퓨터를 포함한 4명 전원이 5판을 마쳤습니다. 첫 세 판의 최하위 참가자도 탈락하지 않았으며, 최종 점수 17·13·13·8점에서 13점 두 명을 공동 2위로 표시했습니다.
- 온라인 두 탭: 같은 방에서 두 참가자가 5판을 끝까지 진행했습니다. 양쪽 최종 점수표가 돈가스 제안자 10점·1위, 국밥 제안자 9점·2위로 일치했습니다. 점수전 뒤 시상식에서 메뉴 승낙 화면으로 이어지는 것도 양쪽에서 확인했습니다.

기존 campus4에서는 30종 480개 시드 경기의 종료·순위·판정·상태 크기와 학과 선택·의상, 8명 주문 엔딩, 세로·가로 조작 화면을 점검했습니다. 화면 점검 기준은 390×844·844×390 뷰포트이며 모든 실제 기기나 모든 경기 시점을 검증한 것은 아닙니다. points5의 실제 공개 멀티 완주 확인 범위는 위 두 탭·2인전입니다.
