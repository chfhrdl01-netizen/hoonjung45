# 점심결재 대작전 · quality7

[게임 열기](https://chfhrdl01-netizen.github.io/hoonjung45/?v=party30-20261115-quality7)

대구대학교 점심 메뉴를 친구들과 함께 정하는 2~8인 브라우저 게임입니다. 기존 GitHub Pages와 실시간 방을 유지하며 30종의 조작·판정·화면을 개선했습니다.

## 진행 방식

1. 캐릭터는 `?`로 시작합니다. 학과·캐릭터와 메뉴를 직접 선택해야 준비할 수 있습니다. 호스트도 미선택 준비·시작 요청을 거절합니다.
2. 전원이 **중복 없는 랜덤 4판 + 30초 피날레 대난투**에 참여합니다. 낮은 순위여도 다음 판에 계속 참여합니다.
3. 매판 순위 점수를 합산합니다. 4명이면 4·3·2·1점, 동순위는 같은 점수입니다. 마지막 난투도 같은 배점이며 추가 결승이나 두 배 점수가 없습니다.
4. 난투는 전원 체력 100·동일 크기로 시작하고 쓰러져도 안전한 위치에서 보호받으며 복귀합니다. 명중·KO를 보상하고 사망 감점을 800점으로 조정했습니다. 일반 단판 생존전은 생존 규칙을 유지합니다.
5. 최종 점수표·시상식 → 메뉴 승낙 → 희망자 커피 게임 → 공동 엔딩 순서입니다. 공동 1위는 공동 순위를 유지하며 대표 메뉴만 한 번 추첨합니다.

메뉴 이의는 신청자당 한 번입니다. 패한 방어자는 다시 이의할 수 없고, 메뉴 이의전으로 확정 누적 순위가 바뀌지 않습니다. 시상식은 우승자 소감을 실시간으로 표시하고 확인 후 넘어갑니다. 엔딩은 건너뛸 수 없으며 커피 배달 장면 13초에 참가자의 확정 주문을 보여주고 모두 로비로 돌아갑니다.

## 화면과 조작 개선

- 30종마다 목표·득점 방식·요령과 짧은 시작 안내를 제공합니다. 득점·실수 피드백은 조작부 안에 표시해 경기장을 가리지 않습니다.
- 조준 점선, 공격 범위, 풍선 받기 구역, 주차 방향, 난투 체력 막대와 재사용 상태를 표시합니다. 조준 미리보기는 참고용이며 실제 충돌 판정은 호스트 엔진이 담당합니다.
- PC는 내 경기장을 크게, 상대 경기장은 작은 미리보기로 표시합니다. 모바일 스포츠는 내 경기장을 세로 공간까지 넓히며 핀·공·캐릭터를 키웠습니다.
- 실제로 쓰는 방향 버튼만 표시하고 충전·발사·회수·대기 상황에 맞춰 액션 문구가 바뀝니다. 키보드 조작도 유지합니다.
- 내 캐릭터와 목표·위험 구역의 대비를 높였으며 난투 바닥에는 세 가지 시각적 테마가 있습니다. 테마 장식은 충돌 벽을 의미하지 않습니다.
- 화면 방향 변경 시 눌린 입력을 해제합니다. 효과음은 기본 OFF이며 움직임 줄이기 설정을 존중합니다.

## 소스와 빌드

[기능별 소스 위치](work/source/README.md)를 참고하세요. 원본은 `work/`의 기능별 모듈이며 `work/source/manifest.json`이 결합 순서와 배포 버전을 관리합니다. `work/base.html`은 HTML 템플릿입니다.

```sh
node work/build.mjs
```

| 배포 파일 | 역할 |
| --- | --- |
| `index.html` | 약 22KB의 화면 HTML |
| `assets/styles-quality7.css` | 화면·기기별·게임별 스타일 |
| `assets/app-quality7.js` | 방 통신·게임 판정·진행·화면 코드 |

같은 세 파일을 `dist/`에도 생성합니다. CSS·JS를 먼저 배포한 후 `index.html`을 반영합니다. 기존 캐시 방문자를 위해 이전 버전 자산은 보존합니다. 방 통신·메인 앱·장식의 기존 세 실행 범위를 유지하며 소스 조각을 각각 ES 모듈로 불러오지 않습니다.

QA 화면은 `node work/build-qa.mjs`로 별도 생성합니다. 테스트용 참가자·상태 주입 코드는 공개 게임에 포함하지 않습니다.

30종을 2인·8인, 두 시드, 일반·점수전 변형으로 반복한 480회 시뮬레이션에서 종료·동순위·결정론·기권·호스트 권한과 종료 후 입력 차단을 확인했습니다. 최대 경기 32초, 최대 공개 상태 15,613자, 최대 객체 88개였습니다. 조준·상태 표시는 반복 렌더링 시 DOM 수가 늘지 않는지 확인했습니다.
