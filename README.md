# 점심결재 대작전 · secret8

[게임 열기](https://chfhrdl01-netizen.github.io/hoonjung45/?v=party30-20261116-secret8)

대구대학교 점심 메뉴를 친구들과 함께 정하는 2~8인 브라우저 게임입니다. 방에 모여 캐릭터와 메뉴를 고르고, 30종 미니게임의 순위 점수를 합산해 대표 메뉴를 정합니다.

## 게임 진행

1. 캐릭터는 `?`로 시작합니다. 학과·캐릭터와 메뉴를 직접 선택해야 준비할 수 있으며 호스트도 이를 확인합니다.
2. 전원이 **중복 없는 랜덤 4판 + 최대 30초 피날레 대난투**에 참여합니다.
3. 매판 순위 점수를 합산합니다. 4명이면 4·3·2·1점이고 동순위는 같은 점수입니다. 마지막 난투에도 같은 배점을 적용합니다.
4. 생존 게임에서 죽으면 **그 판은 관전**합니다. 판 안에서 부활하지 않으며, 생존 순위에 따른 점수를 받은 뒤 **다음 미니게임에 전원 다시 참여**합니다.
5. 최종 점수표·시상식 → 메뉴 승낙 → 희망자 커피 게임 → 공동 엔딩으로 이어집니다. 공동 1위는 공동 순위를 유지하고 대표 메뉴만 한 번 추첨합니다.

메뉴 이의는 신청자당 한 번입니다. 이의를 받고 패한 이전 제안자는 재도전할 수 없으며, 메뉴 이의전으로 확정 누적 순위가 바뀌지 않습니다. 우승 소감은 타이핑하는 대로 공유되고 확인 후 넘어갑니다.

## 엔딩의 작은 별

중앙의 큰 인스타그램 카드와 크레딧의 아이디 노출을 제거했습니다. 왼쪽 아래 작은 `✦`를 누르면 `@mid_jhs` 링크가 나타납니다. 키보드 Enter·Space로도 열고 닫으며, 새 엔딩·종료·연결 해제 때 다시 접힙니다. 발견 여부는 이 기기의 표시 상태이고 공유 엔딩 시간이나 게임 결과에 포함하지 않습니다.

엔딩은 건너뛸 수 없습니다. 커피 배달 장면에서 참가자의 확정 주문을 보여주고 엔딩 종료 시 모두 로비로 돌아갑니다.

## 화면과 캐릭터

PC는 경기장과 정보 영역을 나눕니다. 모바일 스포츠는 내 경기장을 세로 공간까지 사용하고 실제로 필요한 방향 버튼만 표시합니다. 화면 크기·방향이 바뀌면 눌린 입력을 해제합니다. 목표·득점·조작 안내는 게임별로 제공하며 정보를 접고 펼칠 수 있습니다.

118개 학과·전공과 시설물관리 역할, 학과별 16종 의상을 제공합니다. 학과와 의상에 따른 경기 능력치 차이는 없습니다. 근로생은 목록에서 제외했으며 학과 자료의 범위와 출처는 `work/departments-official.json`에 있습니다.

## 소스와 빌드

[기능별 소스 위치](work/source/README.md)를 참고하세요. `work/source/manifest.json`이 기능별 원본의 결합 순서와 배포 버전을 관리하고, `work/base.html`은 HTML 템플릿입니다.

```sh
node work/build.mjs
```

| 배포 파일 | 역할 |
| --- | --- |
| `index.html` | 화면 HTML |
| `assets/styles-secret8.css` | 기기별·게임별 스타일 |
| `assets/app-secret8a.js` | 방 통신·판정·진행·화면 코드 |

같은 세 파일을 `dist/`에도 생성합니다. CSS·JS를 먼저 배포하고 마지막에 `index.html`을 반영합니다. 이전 캐시 방문자를 위한 자산은 보존합니다. 방 통신·메인 앱·장식의 세 실행 범위를 유지하며 소스 조각을 각각 ES 모듈로 불러오지 않습니다.

`node work/build-qa.mjs`는 개발용 화면을 별도로 생성합니다. 테스트 참가자·상태 주입과 장면 고정 코드는 공개 게임에 포함하지 않습니다.
